IPH CRM — FULL FIXED CODE PACKAGE

Files:
1. IPH_CRM_GAS_Fast_Authentication_Optimized.gs — Google Apps Script backend.
2. IPH_CRM_No_PIN_Pattern.html — HTML frontend with PIN/pattern lock UI removed and login timeout/error handling.

INSTALL
1. BACK UP the current Apps Script Code.gs and HTML file first.
2. Open the Apps Script project connected to your CRM spreadsheet.
3. Replace Code.gs with the contents of IPH_CRM_GAS_Fast_Authentication_Optimized.gs. Save.
4. Deploy > Manage deployments > Edit the existing Web app deployment > select New version > Deploy.
   Keep the same deployment URL where possible. Ensure the deployment runs as the intended owner and access settings match your organization.
5. Open IPH_CRM_No_PIN_Pattern.html in an editor and confirm its GAS_URL constant matches the web app deployment URL. It currently points to the deployment URL already configured in the supplied frontend.
6. Host/publish the HTML file in the same way you currently host your CRM, then test.

TESTS
- User with TOTPEnabled TRUE: password must lead to OTP challenge; correct TOTP or unused recovery code should complete login.
- User with TOTPEnabled FALSE: password-only login should complete.
- Wrong password and wrong OTP should be rejected.
- Inventory and center read/write should still work for authorized sessions.
- Check Apps Script > Executions for login duration/errors.

NOTES
- This package uses the supplied CRM schema and existing deployment URL. It has not been tested against your live Google Sheet from this environment.
- Keep a backup before deployment. Do not share the web app URL or recovery codes publicly.
- Password hashing remains enabled; the configured PBKDF2 iteration count is 12,000 in this optimized version. This is a security trade-off and should be reviewed for your organization's requirements.
