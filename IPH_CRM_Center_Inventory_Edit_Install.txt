IPH CRM - CENTER INVENTORY EDIT ACCESS

Files:
- IPH_CRM_Center_Asset_Transit_Fixed.gs (Google Apps Script backend)
- IPH_CRM_Center_Asset_Transit_Full_Frontend.html (frontend)

Changes:
- Center users can add and edit assets assigned to their own center.
- Center writes are row-level; they do not clear or replace the whole inventory sheet.
- Server verifies the authenticated center and prevents editing assets located at other centers.
- Center users cannot change an asset's Location to another center through the general inventory write API.
- Transit columns remain controlled by the separate transit endpoint.
- Admin/Super Admin retain existing bulk inventory write access.

Install:
1. Back up current Code.gs and HTML.
2. Replace Code.gs with the supplied backend file.
3. Replace the current frontend HTML with the supplied frontend file.
4. Save both.
5. Deploy > Manage deployments > Edit > New version > Deploy.
6. Reload the CRM and test with a center account: edit one asset at its own center, save, then verify Google Sheets.
7. Also test that the center account cannot edit an asset assigned to a different center.

Important:
- This package is syntax-checked but not tested against the live Google Sheet.
- Keep a backup and test with one asset first.
